4. 操作結果が他画面に波及する場合（打刻→勤怠、課題→エスカレーション）はトースト内にリンクを付け、波及先を確認できるようにする

### 5.8 権限設定の拡張（メニュー＞タブ＞項目＞参照/更新 + AIの参照範囲。改修依頼 2026-08-18 = F-16-8/9/10）

- **`/masters/permissions` の表示モードを 3 タブへ**: 権限表（既定）／**AIの参照範囲（新設）**／ルール一覧。
  `v-show` 切替でタブ往復しても各モードの選択状態を保持（既存の設計判断を踏襲）。
- **権限表の階層拡張**（`MastersPermissionMatrix`）: 行ツリーを ページ > **タブ・機能** > 項目 > **項目の更新** の
  最大 4 階層へ。①**タブ行**（`tab:<key>`・TAB_PERMISSION_CATALOG の 6 ページ = 日報/週報/月報/稟議/改善要望管理/シフト表
  〔週報・月報は独立機能キー = 改修依頼 2026-08-20 第2バッチ〕。
  ✓ = 利用可 / × = 利用不可。管理者限定タブはロールガードが基底 = allow でも非管理者へ開放されない旨を脚注に明記）
  ②**項目の更新行**（`<項目>:write`・マスタ項目のみ = API enforcement の範囲と一致。✓ = 更新可 / × = 更新不可。
  **参照＞更新: 項目の参照がそのレイヤで不可なら更新セルは操作不可 + 「更新不可（項目の参照が不可のため）」表示** =
  表示が実挙動〔canEditField〕と一致）。セル操作（明示化・引き継ぎへ戻す取消・フェイルセーフ順序）は既存と同一。
- **「AIの参照範囲」タブ（`MastersAiScopeMatrix` = 新設）**: データ種類（改善のタネ/勤怠/タスク計画/日報・週報 =
  `AI_REFERENCE_DATATYPES`）を UiTabBar で選択 → **列 = 参照者**（ロール/役職/個人レイヤ切替。個人は列メンバーを選択式 =
  権限表と同 UX）× **行 = 対象（登録者）**（全メンバー一括 `ai-scope:*` / ロール / 役職 / 個人 = 行に追加するメンバーを選択式）。
  セルは **参照可（明示 allow）/ 参照不可（明示 deny）/ 既定（破線 = 権限表の参照権限に従う）の三値をクリックで循環**
  （既定 → 参照可 → 参照不可 → 既定。既定へ戻す = 明示ルールの論理削除 = 取消フロー・原則9.5。無効ルールの復元再利用・
  deny を残す順序のフェイルセーフは権限表と同一）。**本人セル（参照者 = 登録者）は常に参照可で操作不可**。
  脚注にデータ種類ごとの既定値と解決順（個人 > 役職 > ロール > 一括 > レガシー二値 > 権限表既定・機能 deny 最優先)を明記。

  フォールバック分岐を持たない）、「利用できるタブがありません」の空状態を表示する（フェイルクローズ = R1/R2 レビュー反映）**。
